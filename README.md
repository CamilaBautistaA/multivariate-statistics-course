
# Técnicas Multivariadas

Repositorio académico para la asignatura **Técnicas Multivariadas** del Departamento Académico de Estadística e Informática de la **Universidad Nacional Agraria La Molina (UNALM)**.

## 📋 Unidades Académicas y Contenidos

### Unidad 1: Introducción a los Métodos Multivariados e Inferencia Multivariada (Semanas 1-3)

- [ ] Fundamentos de los métodos multivariados y clasificación de aplicaciones.
- [ ] Distribución normal multivariante.
- [ ] Inferencia respecto a un vector de medias.
- [ ] Inferencia respecto a dos vectores de media (muestras dependientes e independientes).

### Unidad 2: MANOVA y MANCOVA (Semanas 4-6)

- [ ] Análisis de Variancia Multivariado (MANOVA): modelos, supuestos y criterios de decisión.
- [ ] Análisis de Covariancia Multivariado (MANCOVA): modelos, supuestos y criterios de decisión.

### Unidad 3: Análisis de Regresión Multivariada (Semanas 7-8)

- [ ] Modelo de regresión multivariada, supuestos, criterios de decisión y aplicaciones.

### Unidad 4: Componentes Principales, Análisis Factorial y Análisis de Correspondencia (Semanas 9-11)

- [ ] Método de Componentes Principales (PCA), supuestos y aplicaciones.
- [ ] Método Factorial, supuestos y aplicaciones.
- [ ] Análisis de Correspondencia simple y múltiple, supuestos y aplicaciones.

### Unidad 5: Análisis Discriminante Lineal, Cuadrático y Regularizado (Semanas 12-13)

- [ ] Análisis Discriminante Lineal (LDA), supuestos y aplicaciones.
- [ ] Análisis Discriminante Cuadrático (QDA), supuestos y aplicaciones.
- [ ] Análisis Discriminante Regularizado (RDA).

### Unidad 6: Regresión Logística Dicotómica, Multinomial y Ordinal (Semanas 14-16)

- [ ] Regresión logística dicotómica, supuestos y aplicaciones.
- [ ] Regresión logística multinomial y ordinal.
