01 / INTRODUCCIÓN

Un método de clasificación

QDA estima una distribución multivariada para cada grupo y asigna una observación a la zona con mayor probabilidad posterior.

Permite que cada zona tenga su propia matriz de covarianzas: las fronteras entre clases pueden ser curvas.

X | Zona = g ∼ Normal multivariada(μg, Σg)
QDA también se denomina ADC. Zona es una categoría conocida durante el ajuste; el objetivo predictivo es clasificar individuos cuya zona no se proporciona al modelo.

04 / SELECCIÓN

Lambda de Wilks: aporte adicional

Λ = |E| / |T|   ·   Λ parcial = Λ nuevo / Λ previo

Forward: probar cada candidata junto a las ya incluidas, elegir la que minimiza Λ y aceptar si su prueba F parcial cumple p < 0.05.

# Equivalente de uso con klaR:
greedy.wilks(Zona ~ Hemoglobina + Proteina + Albumina +
  Creatinina + Colesterol, data = datos, niveau = 0.05)
El código descargable implementa explícitamente Λ y su F condicional: F=(1/Λ parcial−1)(n−G−q)/(G−1), gl=(G−1,n−G−q). No es AIC. Λ evalúa diferencias de medias; no detecta toda la información de covarianzas que QDA puede aprovechar. Sus p son exploratorias con heterogeneidad y tras búsqueda de variables.

11 / AJUSTE EN R

Una covarianza para cada zona

datos$Zona <- factor(datos$Zona,
  levels = c('Puna Humeda', 'Puna Seca'))
modelo <- MASS::qda(Zona ~ Creatinina + Albumina,
  data = datos, prior = c(36, 37) / 73, method = 'moment')
pred <- predict(modelo, datos)
Los priors son 36/73 y 37/73, en el orden de los niveles. method='moment' usa covarianzas muestrales. No se usa CV=TRUE. La clasificación MAP supone igual costo de error; Puna Seca se define como positiva para reportar métricas binarias.
12 / REGLA DE DECISIÓN

Densidad, dispersión y prior

δg(x) = log πg − ½ log |Σg|
− ½ (x−μg)ᵀ Σg⁻¹ (x−μg)
P(g | x) = exp δg(x) / Σh exp δh(x)
Se elige la zona de mayor posterior. El determinante penaliza dispersión y el término de Mahalanobis mide distancia adaptada a cada grupo. Se cancela la constante normal común; cada individuo recibe dos probabilidades que suman 1.

28 / PRECISION–RECALL

Detectar Seca y acertar al anunciarla

Área bajo la curva PR (trapezoidal)=0.98444 para Puna Seca. La curva une linealmente los puntos obtenidos al variar el umbral. La línea discontinua es la prevalencia 37/73=0.50685. Precision=TP/(TP+FP), recall=TP/(TP+FN). El origen (recall=0, precision=1) es convencional; no representa precisión observada sin anuncios positivos.

Para Puna Seca, el área equivale a una precision media de aproximadamente 98.44%, ponderada por los incrementos de recall, usando interpolación lineal. Está muy por encima de la referencia 50.68%.

No significa 98.44% de exactitud, recall ni precision a un umbral particular: a 0.5 la precision es 92.11% y el recall 94.59%. AP usa la precision del extremo de cada incremento de recall, mientras AUPRC promedia ambos extremos; aquí son próximas pero distintas. Ambas se calculan con los mismos 73 casos usados para seleccionar y ajustar: describen desempeño aparente y no garantizan generalización. La prevalencia es la referencia de una regla sin habilidad, no el límite inferior universal del área.
29 / ROC Y PR

Dos preguntas complementarias

CurvaPregunta central
ROC¿Cuántos Seca detecto para cierta tasa de falsos positivos?
Precision–Recall¿Qué fracción de mis anuncios Seca es correcta, y cuántos Seca recupero?
PR resulta especialmente útil cuando interesa una clase rara y el costo de falsos positivos, porque su precision refleja la prevalencia. Aquí no hay desbalance importante y ninguna curva es universalmente mejor. AUPRC, AP y AUC ROC tienen distintas definiciones y referencias; no se comparan como si fueran la misma magnitud.
30 / IMPORTANCIA QDA

Qué ocurre si se pierde una variable

Con el modelo fijo, se permuta cada variable 300 veces y se mide el incremento medio de LogLoss frente al original (semilla 84). Creatinina: +2.733; Albumina: +0.080. Mayor incremento indica mayor dependencia predictiva en esta muestra. No es un porcentaje ni efecto causal, no se reentrena y no es validación externa; correlaciones y combinaciones poco plausibles afectan la interpretación.

32 / CONCLUSIONES

Separación alta, evidencia con límites

Wilks α=0.05: selecciona Creatinina y Albumina.

QDA: covarianzas diferentes, 68/73 aciertos aparentes, AUC ROC 0.981, AUPRC trapezoidal 0.98444 y AP 0.98464.
