01 · INTRODUCCIÓN

Clasificar entre más de dos grupos

El ADL múltiple asigna una observación a uno de varios grupos previamente conocidos. Combina predictores numéricos para separar los centros de los grupos respecto de su variación interna.

Número de funciones ≤ min(p, G − 1)
En este caso: min(3, 3 − 1) = 2
Es un método supervisado de clasificación y representación de separación. “Múltiple” se refiere aquí a tres grupos. Las etiquetas se tratan como categorías: el modelo no impone un orden ordinal a Bajos, Medios y Altos.

03A · SELECCIÓN

Lambda de Wilks con aporte condicional

Λ = |E| / |T|
Λ parcial = Λ(modelo con candidata) / Λ(modelo previo)

Selección forward: se evalúa cada variable restante junto a las ya incluidas. Entra la que minimiza Lambda si su F parcial tiene p < 0.10. Se detiene si la mejor candidata no cumple ese nivel.

E es la matriz de variación dentro de grupos y T la total. No se usa un orden fijo de columnas ni un criterio AIC. F parcial = (1/Λ parcial − 1)(n−G−q)/(G−1), con gl G−1 y n−G−q, donde q es el número de variables ya incluidas. El nivel de entrada 0.10 se adopta para incluir patrocin, según la actualización solicitada; con 0.05 no entraría. La selección no garantiza el mejor subconjunto predictivo y sus p son exploratorios.

25 · DEFINICIONES

Métricas multiclase sin confundir promedios

F1ₖ = 2TPₖ / (2TPₖ + FPₖ + FNₖ)
Macro F1 = promedio de F1ₖ
Macro recall = promedio de sensibilidadₖ
MCC = [n·tr(C) − Σ rₖcₖ] /
√[(n² − Σrₖ²)(n² − Σcₖ²)]
C es la matriz de confusión, r y c sus totales de filas y columnas. MCC usa toda la tabla y va de −1 a 1 cuando está definido. La exactitud balanceada multiclase usada aquí es macro recall, distinta de promediar las exactitudes balanceadas OVR de caret.
